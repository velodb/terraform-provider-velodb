# velodb_byoc_credentials (Data Source)

Use the *velodb_byoc_credentials* data source to list BYOC credential
configurations in your VeloDB Cloud organization. This is the easiest way to find
the numeric `credential_id` required to
[import](../resources/byoc_credential.md#import) a `velodb_byoc_credential`
resource (import ID `aws/<credential_id>`), or to feed `credential_id` into a
`velodb_byoc_network` resource.

## Example Usage

```terraform
data "velodb_byoc_credentials" "all" {
  cloud_provider = "aws"
  region         = "us-east-1"
}

# Map of name -> id, handy for locating the ID to import.
output "credential_ids" {
  value = { for c in data.velodb_byoc_credentials.all.credentials : c.name => c.id }
}
```
