# velodb_encryption_keys (Data Source)

Use the *velodb_encryption_keys* data source to list encryption keys registered in
your VeloDB Cloud organization. This is the easiest way to find the numeric
`encryption_key_id` required to
[import](../resources/encryption_key.md#import) a `velodb_encryption_key`
resource (import ID `aws/<encryption_key_id>`), or to feed
`tde_encryption_key_id` / `ebs_encryption_key_id` into a `velodb_warehouse`
resource.

## Example Usage

```terraform
data "velodb_encryption_keys" "all" {
  cloud_provider = "aws"
  region         = "us-east-1"
}

output "encryption_key_ids" {
  value = { for k in data.velodb_encryption_keys.all.encryption_keys : k.name => k.id }
}
```
