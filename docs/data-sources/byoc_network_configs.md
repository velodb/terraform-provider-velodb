# velodb_byoc_network_configs (Data Source)

Use the *velodb_byoc_network_configs* data source to list BYOC network
configurations in your VeloDB Cloud organization. This is the easiest way to find
the numeric `network_config_id` required to
[import](../resources/byoc_network.md#import) a `velodb_byoc_network` resource.

~> **Note** The network import ID is `aws/<network_config_id>/<credential_id>`,
but the network configuration does not report its `credential_id` (the credential
association lives on the warehouse). Pair the `network_config_id` from this data
source with the credential you manage — use the
[velodb_byoc_credentials](byoc_credentials.md) data source to look one up.

## Example Usage

```terraform
data "velodb_byoc_network_configs" "all" {
  cloud_provider = "aws"
  region         = "us-east-1"
}

output "network_config_ids" {
  value = { for n in data.velodb_byoc_network_configs.all.network_configs : n.name => n.id }
}
```
